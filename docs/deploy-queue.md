## 대기 중
- 정보글 본문에서 품목 페이지 링크 지원: 예) `[품목:계란]` → "계란 최저가 모아보기" 링크
  (지금은 상품 카드 `[상품:ID]` 만 지원 — 품목 페이지로 내부 링크를 걸면 색인·상위노출에 도움)
- 가격 두 줄 표시 (쿠팡처럼): 와우가 / 일반가 — 11/7부터 option_price_history.source 로 API 별 가격을 모으는 중.
  며칠 뒤 같은 옵션의 search(와우가 추정) vs best·goldbox(일반가 추정) 가격을 비교해 확인한 뒤 구현
- 옵션별 가격 목록 + '여러 개 사면 얼마 절약' (product_options 에 11/7부터 수집 중)
- 단위 가격 표시 (상품명에서 개수·용량 읽어 1개당·100g당)
- 관리자 화면 상단에 수집 현황판: 24시간 안 가격 확인 비율, 오늘 확인한 상품 수, 소개글 있는 상품 수, 최근 갱신 상품
- 관리자 상품 목록에 '소개글 없는 상품만' 체크 (API 는 nodesc=1 로 이미 지원)
- 상품 페이지에 '가격 확인일'이 오래된 경우 표시 (예: "3일 전 확인") — 재확인 작업과 함께 신뢰도 표시
