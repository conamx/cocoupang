## 11/16 새 넷리파이 계정 배포에 넣은 것 (브랜치 claude/dec-ui)
- 판매종료 의심 상품: 홈·카테고리·키워드·검색·특가 목록·사이트맵에서 빼기, 상품 페이지는 남기고 "판매 종료(또는 일시품절)" 안내 + noindex
  + "지금 판매 중인 같은 상품" 후보 (product_successors, 우리 사이트에 있으면 상품 페이지로, 없으면 쿠팡 링크)
- 가격 확인이 이틀 넘게 지난 상품: "N일 전에 확인한 가격" 안내
- 옵션 갈아타기 안내: "○월 ○일부터 대표 옵션이 바뀌어 ○○ 기준으로 기록" (30일 안의 변경만)
- 옵션별 가격 표 (최근 7일 본 옵션, 단위 가격 + "N% 절약")
- 단위 가격 (상품명의 용량·개수로 100g·100ml·1개당, 참고용) — src/lib/unit-price.ts
- 구조화 데이터: category 제거, offers.validFrom(가격 확인일) 추가, 판매종료면 OutOfStock
- 관리자: 상단 수집 현황판(24시간 확인 비율·오늘 확인·3일 넘음·판매종료·소개글), "소개글 없는 상품만" 체크
- 정보글: 한 줄 `[품목:계란]` 또는 `[품목:계란, 우유]` → 품목 페이지 링크

## 하지 않기로 한 것
- 와우가/일반가 두 줄 표시: 11/16 확인 결과 같은 옵션·같은 날 검색 API 와 베스트·골드박스 API 가격이 2,309쌍 중 2,021쌍(88%) 같음,
  다른 경우도 양쪽 방향으로 섞여 있음(하루 중 가격 변동) → 'API 별로 와우가/일반가' 가설은 틀림. 두 가격을 받을 방법이 없어 보류.
